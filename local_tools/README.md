# Local Tools & Helpers

This is a set of tools that help with some tasks and are meant to be used with **shellmaster** and the main projects you're (we all)  working on. They are basically a bunch of useful extras that can make your work easier.

-  **[vector_hub](vector_hub/)**: This helps you create a special `skill.db` for the hub that's really focused - check out the [vector_hub README](vector_hub/readme.md) for more info. It stops your tokens from getting out of control, so you don't waste them.
-  **[local quart Bridge](brige)**: This gives you a safe connection and a local server to run the `shellmaster-cli` right on your own computer.
- -**[Desktop UI](../DESKTOP_UI)**: This is a separate interface for your computer that lets you work with your server or online space without using a web browser. It's still a work in progress - about 80% done - and we're open to making it better.
